# MAISON DROP

Premium mobile-first storefront prototype for Instagram-to-WhatsApp commerce.

## Launch checklist
1. Replace the placeholder WhatsApp number in `index.html`.
2. Replace product photo slots with licensed product images.
3. Confirm supplier, stock, sizes, colors, prices and delivery terms.
4. Replace placeholder product prices/descriptions.
5. Add real GLB models later; the 3D viewer structure is already prepared.
6. Enable GitHub Pages from Settings → Pages → Deploy from branch → main → /(root).

## Product architecture
Each product has an id, category, price, description, WhatsApp message and 3D-ready flag.
